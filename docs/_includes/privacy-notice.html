Beim Abruf erhält GitHub die für die Auslieferung erforderlichen technischen Daten. Dazu gehören Ihre IP-Adresse, die angeforderte Seite sowie, je nach Anfrage, Datum und Uhrzeit, Browser- und Geräteangaben und die zuvor besuchte Seite (Referrer). GitHub dokumentiert ausdrücklich, dass IP-Adressen von Websitebesuchern zu Sicherheitszwecken protokolliert und gespeichert werden.

Die Verarbeitung dient der Bereitstellung und Absicherung der Website. Rechtsgrundlage für die von mir veranlasste Verarbeitung ist Art. 6 Abs. 1 lit. f DSGVO. Mein berechtigtes Interesse besteht in einer zuverlässig erreichbaren und sicheren Website. Die Speicherdauer der technischen Protokolle wird von GitHub bestimmt; eine feste Frist speziell für GitHub-Pages-Zugriffsprotokolle wird in den verlinkten Datenschutzhinweisen nicht genannt.

GitHub verarbeitet Daten auch in den USA und weiteren Ländern. Als Garantien für internationale Übermittlungen nennt GitHub insbesondere das EU-US Data Privacy Framework und Standardvertragsklauseln der Europäischen Kommission. Einzelheiten zu Empfängern, Übermittlungen, Garantien und Speicherdauer finden Sie in der Datenschutzerklärung von GitHub.

Keine Analyse- oder Marketingdienste

Die Website bindet keine Analyse- oder Marketingdienste ein und setzt selbst keine Cookies, keinen Local Storage und keinen Session Storage. Schriftarten, Bilder und Plattformlogos werden zusammen mit der Website ausgeliefert, nicht von externen Schrift- oder Widget-Anbietern nachgeladen.

Es gibt kein Kontaktformular, kein Benutzerkonto und keine eingebetteten Social-Media-Widgets. Links zu anderen Websites übertragen durch die Website allein noch keine Daten an das verlinkte Ziel. Erst wenn Sie einem Link folgen, verarbeitet der jeweilige Anbieter Daten nach seinen eigenen Datenschutzhinweisen. E-Mail- und Telefonlinks öffnen die entsprechende Anwendung auf Ihrem Gerät.
